# Физическая модель NewModel

## Что это

На экране прямоугольники (ноды). Между некоторыми нарисованы линии (связи). Физика решает, как ноды двигаются, чтобы не налезать друг на друга и не улететь далеко.

## Как работает каждый кадр

Компьютер 60 раз в секунду повторяет один и тот же цикл:

### 1. Джитер — случайное подёргивание

Каждая нода сдвигается на ±1 пиксель по X и Y. Это как вибрация стола. Зачем? Если ноды стоят вплотную, расстояние между ними = 0, и физика не может посчитать силу (деление на ноль). Джитер создаёт крошечное расстояние, и физика начинает работать.

### 2. Силы между парами нод

Для каждой **пары** нод (i, j) компьютер смотрит: связаны они или нет? И считает силу по разным формулам.

#### Притяжение

Все ноды притягиваются друг к другу. Сила **постоянная** (не зависит от расстояния):

```
F = AttractionK
```

Коэффициент = 0.001. Очень слабое. Просто не даёт нодам улететь за экран.

#### Отталкивание

Здесь самое важное. Сила зависит от того, **связаны ли ноды**.

**Формула:**
```
F(x) = S − k × x
```

- **S** = 500 — максимальная сила (когда ноды вплотную)
- **p** = 10 — сила на краю зоны
- **k** = (S − p) / activeZone — наклон прямой
- **x** — расстояние между центрами нод

**Какая зона (activeZone) используется:**

| Если ноды... | Зона (zoneL) | activeZone |
|-------------|-------------|------------|
| **Связаны** | 2 × min(rA, rB) + 0.02 | 2 × zoneL |
| **Не связаны** | max(Zone3A, Zone3B) | 2 × zoneL |

**Что такое r?** Половина диагонали прямоугольника:
```
r = √(Width² + Height²) / 2
```

Для A (320×160): r ≈ 179. Для B (160×80): r ≈ 80.

**Что такое Zone3?** Максимальная Zone 2 среди связанных соседей ноды. Zone 2 = 2 × r соседа.

Пример для A→B→C (A большая):
- Zone3(A) = Zone 2(B) = 2×80 = **160**
- Zone3(B) = Zone 2(A) = 2×179 = **358**
- Zone3(C) = Zone 2(B) = 2×80 = **160**

### 3. Интеграция — движение

Для каждой ноды:

```
сила = притяжение + отталкивание + трение
ускорение = сила / масса     (масса = 1)
скорость += ускорение × dt
скорость *= FrictionK         (дефолт 0.99, замедление на 1% за кадр)
ограничение скорости: макс 2000 пикс/с
позиция += скорость × dt
```

**Трение** — множитель на скорость. Каждый кадр скорость уменьшается на 1%. Без этого ноды летали бы бесконечно.

## Зоны на экране

Каждая нода окружена пунктирными окружностями:

### Зона 1 — Собственный радиус (r)

Собственное пространство ноды. Половина диагонали прямоугольника.

Для A (320×160): r ≈ **179**
Для B (160×80): r ≈ **80**

Рисуется **тёмной** пунктирной окружностью.

### Зона 2 — Двойная (2 × r)

В два раза больше собственного радиуса. Действует **только для связанных** пар.

Для A: 2×179 = **358**
Для B: 2×80 = **160**

Рисуется **средней** пунктирной окружностью.

### Зона 3 — Наследуемая (макс. Zone 2 соседей)

Вычисляется на основе связанных соседей. Берётся **максимальная** Zone 2 среди всех связанных соседей.

- Zone3(A) = Zone 2(B) = 160 (потому что A связана с B)
- Zone3(B) = max(Zone 2(A), Zone 2(C)) = max(358, 358) = **358**
- Zone3(C) = Zone 2(B) = 160

Действует **только для несвязанных** пар (A↔C).

Рисуется **светлой** пунктирной окружностью.

## Как зоны работают вместе

| Зона | Радиус | Для кого | Формула |
|------|--------|----------|---------|
| 1 | r = √(W²+H²)/2 | Все пары | S − k·x |
| 2 | 2 × min(rA, rB) + 0.02 | Связанные | S − k·x |
| 3 | max(Zone2 соседей) | Несвязанные | S − k·x |

**Важно:** Зоны не суммируются. Для каждой пары используется **одна** зона — в зависимости от того, связаны ноды или нет.

## Дуги и порты

**Порт** — точка на краю ноды. У каждой ноды два порта: левый и правый.

Дуга идёт от правого порта исходящей ноды к левому порту входящей. Можно включить ортогональные дуги (L-образные, горизонталь + вертикаль).

## Примеры графов

**A(big) → B → C:**
- A: 320×160 (r=179), B: 160×80 (r=80), C: 160×80 (r=80)
- Связи: A→B, B→C

**A → B(big) → C:**
- A: 160×80 (r=80), B: 320×160 (r=179), C: 160×80 (r=80)
- Связи: A→B, B→C

## Параметры

| Параметр | Описание | Дефолт |
|----------|----------|--------|
| S | Макс. сила отталкивания | 500 |
| p | Сила на краю зоны | 10 |
| UniversalRepulsionK | (зарезервировано) | 10 |
| AttractionK | Сила притяжения | 0.001 |
| FrictionK | Трение (1.0 = без трения) | 0.99 |
| UseJitter | Дрожание | true |
| MaxSpeed | Макс. скорость (пикс/с) | 2000 |
