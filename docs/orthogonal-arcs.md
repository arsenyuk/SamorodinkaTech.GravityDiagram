# Как работают ортогональные дуги

## Что такое ортогональная дуга?

Представь, что ты рисуешь стрелку между двумя прямоугольниками на бумаге. Но не просто прямой линией — а ломаной, которая состоит **только из горизонтальных и вертикальных сегментов**. Вот это и есть ортогональная дуга.

Почему "ортогональная"? Потому что все углы в ломаной — ровно 90 градусов. Никаких диагоналей.

```
  ┌──────┐                    ┌──────┐
  │  A   │────────┐           │  B   │
  │      │        │           │      │
  └──────┘        │           └──────┘
                  └──────────────┘
```

Это看起来 чище и аккуратнее, чем кривые линии, которые пересекают прямоугольники где попало.

## Откуда берётся дуга?

У нас есть два прямоугольника (ноды) и порт на каждом из них — маленькая точка на стороне прямоугольника, откуда "выходит" дуга.

```
  Порт ──●
         │
  ┌──────┤
  │  A   │
  └──────┘
```

Дуга всегда выходит из порта **перпендикулярно стороне**. Если порт справа — дуга идёт вправо. Если порт снизу — вниз.

## Три формы дуги

Движок умеет строить дуги трёх видов:

### 1. Прямая (2 точки)

Когда порты находятся друг напротив друга на одной линии:

```
  ┌──────┐            ┌──────┐
  │  A   │────────────│  B   │
  └──────┘            └──────┘
```

Простейший случай. Просто горизонтальная или вертикальная линия.

### 2. L-образная (3 точки)

Когда нужно сделать один поворот на 90°:

```
  ┌──────┐
  │  A   │──────┐
  └──────┘      │
                │
         ┌──────┘
         │  B   │
         └──────┘
```

Один локоть — и дуга arrivederci к цели.

### 3. Трёхsegmentная (5 точек)

Когда L-образный путь невозможен (дуга должна "обогнуть" что-то):

```
  ┌──────┐
  │  A   │────┐
  └──────┘    │
              │
              └────┐
                   │  B   │
         ┌─────────┘
         └──────────────┘
```

Три поворота — как letter Z или letter S, но под прямым углом.

## Как движок выбирает форму?

На каждом "тикe" (кадре анимации) движок:

1. **Смотрит на позиции портов** — где находятся точки входа и выхода дуги
2. **Пробует прямую** — если порты на одной оси и направления совпадают
3. **Пробует L-образную** — генерирует два варианта (сначала горизонталь, потом вертикаль, или наоборот) и проверяет, совместимы ли направления
4. **Если ничего не подходит** — строит трёхsegmentную дугу с "обходом"

## Что делает физика?

После того как дуга построена, к её промежуточным точкам (локтям) применяются **силы**:

### Притяжение (пружины)

Каждая точка дуги притягивается к соседним точкам. Как будто между ними натянута резинка. Это делает дугу **короче и проще**:

```
  ДО силы:                    ПОСЛЕ силы:
  ┌──────┐                    ┌──────┐
  │  A   │────┐               │  A   │────┐
  └──────┘    │               └──────┘    │
              │                           │
              └────┐               ┌──────┘
                   │  B   │       │  B   │
         └─────────┘       └──────┘
```

### Отталкивание от нод

Если точка дуги оказалась **внутри** прямоугольника (или слишком близко), она отталкивается наружу. Дуга не должна проходить сквозь ноды.

### Ортогональность

После каждого перемещения точка "привязывается" к оси предыдущего сегмента. Если предыдущий сегмент был горизонтальным — точка двигается только вертикально. И наоборот. Это сохраняет углы ровно 90°.

## Зачем这么多_steps?

На каждый кадр анимации движок делает **много маленьких шагов** (до 240 за раз). Это нужно потому что:

- Силы работают аккуратно — каждый шаг сдвигает точки чуть-чуть
- Много маленьких шагов = плавная анимация
- Одного большого шага было бы недостаточно — дуга могла бы "проскочить" сквозь ноду

## Как дуга "ремонтируется"

Иногда сегмент дуги всё-таки проходит сквозь прямоугольник. Тогда движок:

1. **Находит** пересечение
2. **Вставляет** новую точку-обход
3. **Выравнивает** углы обратно в 90°
4. **Удаляет** лишние точки, которые оказались на одной линии (коллинеарные)

```
  ДО ремонта:                 ПОСЛЕ ремонта:
  ┌──────┐                    ┌──────┐
  │  A   │╲                   │  A   │──┐
  └──────┘ ╲ Node B           └──────┘  │
            ╲                          │
             ╲─────                    └──┐
                                          │
  Сегмент проходит сквозь B    Обход вокруг B
```

## Резюме

| Что | Как |
|-----|-----|
| Форма | Только горизонталь + вертикаль, углы 90° |
| Варианты | Прямая / L-образная / трёхsegmentная |
| Физика | Пружины делают короче, отталкивание убирает из нод |
| Ремонт | Новые точки-обходы при пересечении с нодами |
| Шаги | До 240 маленьких шагов за кадр для плавности |
